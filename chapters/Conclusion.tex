\chapter{Conclusion}%
\label{ch:conclusion}

The measurement of the cross-section of several observables sensitive to
the interference between \ttbar and \tW in the \WbWb final state is performed
using the full Run 2 dataset collected by the ATLAS experiment. 

This is the first measurement in the single lepton channel and its added value,
with respect to the measurements in the dilepton channel, is probing new phase
spaces with the aim of understanding the Monte Carlo modelling and reducing
uncertainties for beyond the Standard Model searches.
Furthermore, the semi-leptonic decay channel provides the opportunity
to measure the hadronic \Wboson boson kinematics in the inclusive \WbWb final
state.

The sensitivity of the analysis is currently limited by the statistics
and by the uncertainty associated to the interference itself.
In some distributions it is also masked by the top quark momentum mismodelling.
Hence, further improvements can be achieved with the data collected in
the Run 3 and by using new Monte Carlo samples that can be optimised with
these measurements.
